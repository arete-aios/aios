## The rule for this file

**Every line here would change within about three weeks.** Anything more durable belongs in a
permanent note with one line and a link here. Anything that has not changed in three months is a
constitution line, not a focus line.

**A pointer, not the content, for anything that has its own file.** A line and a link. Detail lives
where the detail lives. That is why the quarter, the goal, the priorities and the promises are all
one line each below.

**Every date in this layer that is a deadline appears in the Dates table below and nowhere else in
this file.** Dates that belong to a single record, a goal's `by`, a ledger row's check date, live in
that record and are not copied here. Three copies of one date will age apart and start contradicting
each other.

**Nothing is deleted. Anything cut moves to a log with the date it moved**, and the move is reported.

**CEILING: 800 words.** This is the second of the two files loaded on every message, so its size is a
running cost and not a one time one. When an area overflows, the oldest entry moves to its log. A
focus file that grows into a master document stops being read, and an unread focus file is worse than
none, because it still loads and still costs. Count it in tokens at the bottom of this file.
