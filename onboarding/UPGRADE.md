# Add the five methods to a brain that already exists

These instructions are for the assistant. Use them when the folder already holds an AIOS and the owner wants the five starter methods — `EVAL7`, `EXIT7`, `COX7` / `CONTEXT7`, `MEETING7`, `FOCUS7` — brought up to date.

**This is not a rebuild.** Never run `START.md` in a folder that already has a constitution, an onboarding map, or the numbered layer folders. The owner's own text, their added files, their tasks, their finished history, and the paths they chose all stay exactly as they are.

Paste this to start:

```text
Read https://raw.githubusercontent.com/arete-aios/aios/main/onboarding/UPGRADE.md and follow it in this folder. Do not rebuild my AIOS, do not repeat the foundation interview, and change nothing until I approve the list.
```

## 1. Read what is there

Read the constitution, the adapter files, the instructions file, and the index files. Then list the five methods with an honest state for each: `PRESENT`, `MISSING`, `ADAPTED by the owner`, or `UNKNOWN VERSION`. Compare a present file against the public source before calling it current, and say when you could not.

Do not ask the foundation questions again. The business context already exists; if something is genuinely missing, note it and carry on.

## 2. Show only the difference

One list: the files that would be added, and the exact lines that would be added to the index or the adapter. Nothing else. No reorganisation, no renaming, no tidying of folders you were not asked about, no new priorities.

## 3. Write only what was approved

- Add a missing method into the folder this brain already uses for methods, in its existing naming.
- **Never overwrite an adapted method.** Show the difference between the owner's version and the public one and ask which lines they want. An adaptation is usually the owner's work, not drift.
- Do not register a second `CONTEXT7` or `COX7`, and do not create a second project index. If one already exists, the new lines go into it.
- In a full local setup, refreshing `00-system/aios/` never overwrites the active copies in the methods folder.
- Keep every source URL, version, and attribution in the index.

## 4. Prove it, narrowly

Say which paths you actually verified: the five files, the trigger lines, and one safe use of one method. Do not claim a working automation, a connected account, or a tested client surface you did not exercise.

Run it twice if in doubt. A second run must change nothing.

## 5. What this run never does

It never deletes, never archives, never moves the owner's material, never starts an evaluation or an interview on its own, and never sends, publishes, pays, or changes access. Everything outside this list is a separate request.

Test it on a copy first when the brain holds real work. A sample folder with invented data and a saved starting state costs one minute and makes the first run reversible.
