# GEO7 human guide and evidence report

Main instruction: [SKILL.md](../SKILL.md). The guide has Overview, Principles, Workflow, Example and Changes in EN/LV. Detailed workflow is the default; the short diagram differs, while all full step descriptions are identical. The compact fictional B2B example uses the accepted three-priority schema: evidence, business reason, action, responsible role and acceptance check. Copying is local, not publishing.

The guide is supplied separately through APP Download HTML as a standalone file; it is not recursively embedded in its own ZIP. Its manifest/view data can be rebuilt with the separate SKILLS7 community toolkit; no copy of that shared engine or private account configuration is included here. Report generation is separate and uses bundled scripts/report.py, scripts/report_detail.py and assets/.

Reports contain summary, technical diagnostics, sampled-page table, content/identity, acquisition data, AI measurement status, action plan and sources/scope. Each finding connects source/time/scope with a specific next action and check. A parsed-text SHA demonstrates identical sampled HTTP content; it does not establish identical hydrated browser pages. JSON-LD presence and valid syntax are distinct. Unsampled URLs and missing measurements remain unknown.

The supplied report renderer currently uses Latvian labels; source schemas and method instructions are English. report.py writes JSON/MD and standalone HTML with locally embedded fonts/logo. A browser print button invokes its normal print dialog; no PDF export is performed automatically. Keep permitted source JSON alongside the output or preserve its declared links. Do not publish private analytics responses with a public report.

The old guide’s UI history is not bundled because it does not drive this version. Required report fonts and their OFL notices are bundled in full. See [asset rights](../assets/README.md) and [provenance](THIRD-PARTY.md).
