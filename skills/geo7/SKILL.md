# GEO7 — Help useful customers find your website

GEO7 connects technical discovery, audience intent, search competitors, page briefs and measured business outcomes. It produces source-backed priorities rather than a universal GEO score or ranking guarantee. The public Python helpers and their report fonts/licences are included; account credentials, a private broker and a publishing backend are not.

## Start and install

Read [INSTALL.md](INSTALL.md) for the first offline run. A capable AI can use this instruction and [METHOD.md](references/METHOD.md) with supplied HTML/text even without Python. Install the full folder only through your AI host’s documented skills mechanism; an uploaded folder is not proof of activation.

> GEO7 — review this website for my audience and offer. Agree the market, scope and evidence window, inspect what is actually available, then show three prioritised improvements with sources and a clear acceptance check.

Use for public website SEO/AI-search audits, audience-question research and organic acquisition priorities. Ordinary copy editing without a search purpose is not a GEO7 audit. A method/guide request does not run a crawl, access accounts or publish changes.

## Decisions that change the result

- **Qualified intent first.** Select a real customer question, a suitable page and a meaningful next action. High search volume alone is not priority; advertising competition is not SEO difficulty.
- **Technical blockers before new content.** If different intents receive identical HTTP text, verify routing/rendering before writing more copy. A robots/canonical observation alone does not establish an indexing error.
- **Competitors come from an observed SERP.** Record query, market, observation time and URLs. A familiar company without that evidence remains a candidate.
- **P1/P2/P3 express work order.** Justify priority using customer-path significance, evidence strength and an acceptance check. This is judgement, not a measured Google or AI impact scale. Insufficient evidence calls for a verification task.
- **Unknown stays unknown.** Empty GSC rows, HTTP429 and AI error/unknown are not zero. A contact event is not a qualified conversation until linked to actual qualification evidence.

## Work sequence and output

Read the relevant part of [METHOD.md](references/METHOD.md) before acting.

1. Establish site, offer, audience, country/language, desired action, period, output directory, permitted sources and request budget.
2. Audit the bounded public sample or supplied HTML; save source JSON and coverage limits.
3. Map audience questions to intent, metrics when actually observed, current/target pages and useful actions.
4. Compare actual search competitors and sources. Prepare page priorities with observed facts, interpretation and uncertainty separated.
5. Draft a concrete page brief or reviewable change. Preserve source facts, brand and accessibility; external implementation follows specific authorisation.
6. Compare matching periods and actual outcomes. AI citations require saved real search answers, not a normal model’s claim that it cited you.

Deliver a dated scope note, source-backed baseline, question/page map and up to three useful priorities. Each names URL, observation, business implication, action, responsible role and acceptance check. Keep a new evidence prefix per run; do not overwrite previous results.

## Tools, boundaries and AIOS

The public helpers use Python3.10+ standard library. [scripts/README.md](scripts/README.md) states inputs, outputs and side effects; [INPUTS.md](references/INPUTS.md) documents optional data schemas. Only audit.py and performance.py make public HTTP requests. research_plan.py makes a bounded paid-query plan with **zero API calls**; execute it only through a separately authorised provider route and budget. No account collector is bundled.

Raw HTML is not a rendered-browser, Core Web Vitals, indexing or AI-citation test. No automatic deployment, paid retry or schedule is created. Never invent testimonials, prices, traffic, search volume, author experience or qualified leads. Preserve the exact source/date for claims.

In AIOS, Constitution supplies direction and permission, Memory supplies offer/history/evidence, Skills connects review to delivery, Tools supplies actual authorised measurements, and Focus selects the next relevant page. Integration is qualitatively medium: public diagnosis/briefs work standalone, while qualified outcomes require your own measurement/CRM chain. No percentage improvement is implied.
