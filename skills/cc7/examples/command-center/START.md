## Open the actual example

1. Download `cc7-command-center.zip` from this folder and unpack it.
2. In the unpacked folder run `python3 preview.py` (Python 3.9+, no packages).
3. Open `http://127.0.0.1:8765/my/cc-demo` for English or
   `http://127.0.0.1:8765/lv/my/cc-demo` for Latvian.
4. Explore the Gantt, views, light/dark, copy buttons and method links.
5. Stop the local server with Ctrl+C. Nothing runs in the background afterwards.

The download contains the HTML, fonts, local server, view list and portable
recipes. No Node build, account, API key or AI service is needed to open it.
Opening the page makes only local font requests; external GitHub links are
navigation. Copy buttons write a request to your clipboard and run no AI.

## Make it yours

Attach your own brain folder to an AI that can read/write files. Use **Copy CC7**
for the whole workspace or **Copy this view** for a selected section. The copied
request includes essential instructions, source links and the selected view.
If clipboard permission is unavailable, the page shows selectable text instead.

The AI should inspect your permitted short entry points, preserve your existing
structure and adapt one useful view first. It must replace the invented people,
tasks, dates, amounts and audit results with your own evidence or visible
unknowns. Keep the page private; adapt identity and branding to your own work.
Follow your own financial/privacy rules. A blueprint is not a working system.

A chat without file access can prepare instructions but cannot install this.
If your AI cannot fetch links, give it this ZIP and `methods/command-center.md`.
Publishing or connecting accounts is a separate choice. This example includes
no bank, CRM, email or analytics account connection and no background schedule.
