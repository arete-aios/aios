# MIT7 capabilities and limits

Main instruction: [SKILL.md](../SKILL.md). Method: [METHOD.md](METHOD.md).

MIT7 1.0.0 is a consolidated daily planning/closeout method. It is not a historical app restoration and does not install an automatic all-agent morning/evening service.

| Capability | What this package supplies |
| --- | --- |
| Daily proposal | Source/capacity rules and a structure for up to three outcomes; AI must apply them to your actual inputs. |
| Choice and history | User chooses; your existing tracker owns the authorised fields assigned to it. No database/client is bundled. |
| Calendar capacity | Use an authorised calendar or an explicitly unverified user-provided work window. |
| Delivery | The appropriate domain skill performs authorised work; an assignee name is not a dispatched job. |
| Closeout | Dated completed/waiting/blocked/continuing, evidence and next action; current status is not an immutable history. |
| Human guide | Self-contained EN/LV HTML with detailed/short diagrams and the same complete descriptions. It performs no account calls. |

A technical guide check is separate from good AI judgement, actual account access and a completed daily business outcome. The fictional example is not a live run receipt. Keep real private evidence in your own project home.

The optional guide rebuild dependency is the separate SKILLS7 community toolkit. The separately downloaded standalone HTML needs no builder, Python or network. Calendar and tracker integrations require your environment’s supported tools and specific permissions.
