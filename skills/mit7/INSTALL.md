# Install MIT7 and try one small day

Start: [SKILL.md](SKILL.md). This is an AI method; no Python, database or account setup is required.

1. Unzip the complete method folder. Give SKILL.md and references/METHOD.md to your AI. For an offline guide, use APP Download HTML separately and save it as index.html beside SKILL.md; the ZIP deliberately excludes that HTML to avoid recursive embedding.
2. If your AI supports installed skills, use its documented installation location and confirm it can find MIT7. A generic chat can use the same files as attachments or pasted text.
3. Provide a goal, current project facts, commitments and a time window. Keep personal information within the audience you intend.
4. Ask for a proposal first. Choose the outcomes yourself; authorise any writes to your existing list/calendar separately and specifically. The HTML does not connect accounts.

## First small run — synthetic input

“I have 100 minutes. The project already contains a draft proposal. Card A is a 20-minute decision and B is a 40-minute final review; together they form one client-ready proposal. Card C is a 30-minute worksheet review. Propose at most three outcomes, each with done criteria. I choose.”

Expected structure: two outcomes, three supporting cards, 90 planned minutes and 10 minutes reserve. This is the same fictional example shown in the guide. It is a planning estimate, not proof of a real delivery or free calendar.

Choose one outcome, do the authorised work, then say: “MIT7 closeout: here is what was delivered and what is missing.” Expect completed/waiting/blocked/continuing, evidence and the next action. Do not accept tomorrow’s choice automatically.

## Verify a safe limit

Say “I cannot provide calendar access.” The AI should use a stated time window marked as unverified, or keep candidates provisional if no window exists. It must not invent a free calendar, an accepted selection or a completed result.

Use APP Download HTML separately for the self-contained guide; save it as index.html beside the unzipped SKILL.md if you want an offline companion. The ZIP contains the method and resources, and deliberately excludes the guide HTML to avoid embedding itself recursively. To rebuild it, obtain the separate SKILLS7 community toolkit and follow its instructions for an adjacent skill folder or its explicit engine option. That optional tool is not required to use MIT7.
