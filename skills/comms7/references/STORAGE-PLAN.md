# Files and storage

Parent: [SKILL.md](../SKILL.md).

Keep the reusable method, specific helper and examples in the one comms7 package.
Keep real account credentials in the platform's protected credential store.
Neither belongs inside a public report.

Reuse the owner's existing protected review home: one current handoff references
open work and its authoritative IDs; dated review records preserve evidence and
coverage. Choose names and archive retention to fit that established system, not a
new duplicate root per run. Do not relocate existing data automatically.

Tasks remain in the task authority, CRM fields in CRM and accepted project facts
in that project's Memory home. Focus is current attention plus links, not an archive
of private messages. Review snapshots/checkpoints are derived and must be reconciled
with newer authoritative state. A move needs source inventory, recovery, caller/link
updates and an actual readback before the old writer can be retired.
