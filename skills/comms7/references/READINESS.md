# Method and installation readiness

Parent: [SKILL.md](../SKILL.md).

This community package supplies a manual review method, self-contained instructions,
fictional examples and an optional offline Python helper. Its presence is not proof
that any member has installed readers, writers, storage, a recurring runner or alerts.

First acceptance: review one supplied conversation, verify its latest context,
choose a useful action and retain an honest handoff. Then verify each optional
account separately with one real permitted read and coverage evidence. Test an
actual write only within its authorised bounded scope and read it back.

A recurring monitor is a separate acceptance: agreed cadence/audience, reliable
runner, restart/overlap behaviour, protected storage, failure reporting and a useful
first cycle. Do not label a historical manual review as an active monitor.
