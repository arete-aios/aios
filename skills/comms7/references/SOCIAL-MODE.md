# Additional channels and engagement

Parent: [SKILL.md](../SKILL.md).

Incoming LinkedIn messages, notifications, website applications, Facebook or another
channel can join the same decision loop. For each, identify the account, permitted
reader, source coverage and supported writes. Notification access does not prove
message access; a personal token does not imply a scheduler or all API scopes.
Use supplied content when no accepted connection is available.

Proactive engagement is an optional COMMS7 mode: find relevant discussions, suggest
worthwhile comments or draft a post for an agreed community and purpose. Load this
only when requested. Keep it distinct from unresolved personal inbox obligations;
review fit with the owner's North Star and active work. Drafts require source/context
checks and the owner's accepted publishing scope. No scraping workaround, mass
outreach or background schedule is installed by the portable method.

A source's activity check, private messages and notification feed can expose
different data and permissions. Verify each requested coverage boundary; do not
infer full notification, attachment or inbox access from one accepted import.
Incoming activity still passes through the semantic review before it becomes work.
