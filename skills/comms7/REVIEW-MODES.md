# Focused reviews

Parent: [SKILL.md](SKILL.md).

Choose only the mode the request needs: Action, Waiting, replies, own promises,
customer delivery, applications, a named person/project, a date-bounded backlog,
Gmail GTD labels, stable filters, subscription cleanup, selected group discussions
or requested community engagement. These are views of the same evidence and state,
not separate tasks automatically run together.

Preserve newest context and unresolved work in every mode. State excluded accounts,
dates and missing evidence. A request to explain a mode does not read an account.
